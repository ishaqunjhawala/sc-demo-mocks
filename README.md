# sc-demo-mocks

Static JSON fixtures backing Ada solution-consultant demos. **Everything here is
illustrative sample data authored for a sales demo** — resort names are real and
publicly listed, but prices, dates, flight times and availability are invented and
must not be read as any operator's published fare.

No customer data, no PII, no credentials.

- `winter-substitute-packages.json` — three all-inclusive substitute packages
- `winter-package-addons.json` — three purchasable add-ons
